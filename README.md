# Math with Python

Mathematical concepts explored and implemented in **Python**, as part of my self-directed study of mathematics.

Each project follows the same approach:

1. **The mathematics**: the concept is explained, with the key definitions and results.
2. **The implementation**: the method is coded by hand, without relying on a library that solves the problem directly.
3. **The verification**: the results are checked, with graphs or by comparison with a reference library.
